# 🎓 EduPulse AI - Capstone Project
**United Nations SDG 4: Quality Education**

EduPulse AI is a hardware-agnostic, conversational learning platform built to act as a 24/7 personal chatbot tutor. It bridges the gap between limited teacher availability and real-time student needs by serving as an instant concept-clearing hub.

## 🌟 Core Features
* **Adaptive AI Tutor:** Uses Generative AI to explain complex academic concepts using simple analogies.
* **Dynamic Quiz Engine:** Formulates unique multiple-choice questions on-the-fly to test student comprehension.
* **Pomodoro Study Timer:** A built-in productivity tool to help students maintain deep-focus intervals.
* **Analytics Logger:** Captures study session metrics and securely transmits them for progress tracking.

## 🛠️ Technology Stack
* **Conversational Engine:** Botpress Cloud
* **Generative AI:** OpenAI (`gpt-4o-mini`) via Botpress AI Tasks
* **Analytics Endpoint:** REST API Webhook integration

## 📂 Repository Contents
* `bot.bpz`: The complete structural source code and conversational node architecture for the Botpress environment.

## 🚀 How to Run Locally
1. Create a free account on [Botpress Cloud](https://botpress.com/).
2. Create a new blank bot.
3. Go to the bot settings and select **Import**.
4. Upload the `bot.bpz` file found in this repository.
5. Publish and test the chatbot in the Botpress emulator.
